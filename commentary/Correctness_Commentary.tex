	\section{Introduction}
	The following is a correctness commentary on my very own implementation of Ukkonen's algorithm on suffix tree construction.  Ukkonen's is uniquely known for it's online capabilities, formalised by Esko Ukkonen in On-line construction of suffix trees. \\
	Suffix trees themselves were introduced in Linear Pattern Matching Algorithms, as a way to reduce basic string matching in reduced time. \\
	Ukkonen's algorithm went on to become the first online construction of the suffix tree, which allows for usage whilst being created.
	My implementation opts for a more naive approach than most implementation, where instead of being upper bound by linear time, it faces $O(n^2)$.  As with all tradeoffs, there is one such advantage that the loss of suffix arrays will reduce space overhead of the algorithm.  However, this is not noticeable enough to justify its usage.
